CINTA PERDIDA — sitio web inicial

Archivos:
- index.html: portada
- proceso.html: detrás de cámaras
- juego.html: descargas del juego (pendiente de agregar los archivos finales)
- universo.html: personajes y contenido audiovisual
- styles.css: estilos y diseño adaptable
- script.js: menú desplegable
- assets/: logotipos, texturas y recursos gráficos

Para probarlo localmente: abrir index.html en un navegador.
Para publicarlo en GitHub Pages: crear un repositorio, subir el contenido de esta carpeta y activar Pages desde Settings > Pages, usando la rama principal y la carpeta root.

Notas de diseño:
- La carpeta naranja es la portada y el recurso rosa representa su interior.
- La hoja con borde azul se conserva como hoja blanca, no como marco vacío.
- La textura de madera está simulada temporalmente con CSS. Se puede reemplazar por la textura original de Canva cuando la compartas.
- El contenido de descargas está marcado como pendiente hasta recibir los archivos definitivos.

Actualización v2: pins separados en PNG transparentes; sello CONFIDENCIAL sin fondo blanco; pie de página actualizado con Comisión: Lucía Pinto.

Versión 3: pins individuales ampliados y distribuidos por tarjeta; logo FDA con silueta de sello postal; etiqueta colgante 'PÁGINA WEB' junto al logotipo principal. Las imágenes de las tarjetas siguen siendo provisionales.

Versión 4: mapa real integrado en la tarjeta Universo con bordes suavemente difuminados; etiqueta colgante horizontal, inclinada y con el interior del ojal transparente; pins recortados individualmente sin fondo y tarjeta Proceso reducida a un solo pin.

Versión 5: se unificó el nombre de la sección 'Detrás de cámaras' entre inicio, navegación y página interna. Las páginas internas ahora usan la etiqueta colgante horizontal junto al logo para identificar su sección, siguiendo el lenguaje visual de 'PÁGINA WEB'. Se ajustó ligeramente el solapamiento de la etiqueta principal con el logo.

Versión 6: las etiquetas de las páginas internas ahora distribuyen 'Detrás de cámaras' en dos líneas (DETRÁS / DE CÁMARAS) y 'Juego de mesa' en dos líneas (JUEGO / DE MESA), para que el texto respire dentro de la etiqueta. La portada permanece sin cambios. Las tipografías del proyecto quedan pendientes de aplicar hasta confirmar las dos muestras tipográficas enviadas por la usuaria.


Versión 7 — actualización tipográfica
- Cormorant Garamond para textos de lectura y descripciones.
- Josefin Slab para títulos y encabezados de secciones.
- Special Elite se conserva para el lema y elementos de estilo máquina de escribir.
- Se mantienen la estructura, las imágenes, los colores y la composición aprobada de la portada.
- Las fuentes se cargan desde Google Fonts, por lo que la web necesita conexión a internet para mostrarlas.

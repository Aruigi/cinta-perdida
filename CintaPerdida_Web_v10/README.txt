Actualización de contenido para GitHub Pages.

Cambios:

- Universo: archivo de cuatro páginas de anotaciones de interrogatorios (Cintia, Flamert, Terina y Vivi).

Para actualizar el sitio:
1. Descomprimir este ZIP.
2. En GitHub, abrir el repositorio cinta-perdida.
3. Add file > Upload files.
4. Subir el contenido de esta carpeta (incluida assets) a la raíz del repositorio.
5. Confirmar con Commit changes en la rama main.

No subir el ZIP como un único archivo. Mantener index.html y las páginas HTML en la raíz, y los recursos gráficos dentro de assets.
